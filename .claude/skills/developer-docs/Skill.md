## Overview
This Skill provides specialized knowledge for creating comprehensive developer documentation and guides. When writing API documentation, setup guides, code examples, or technical documentation for developers, apply these guidelines to ensure clear, useful, and maintainable documentation.

## API Documentation

- Document all endpoints with clear examples
- Include request/response schemas and examples
- Provide authentication and authorization details
- Document rate limits and usage restrictions
- Include error response codes and messages
- Show example API calls in multiple languages

## Setup and Configuration

- Provide clear prerequisites and system requirements
- Include step-by-step installation instructions
- Document environment variable configurations
- Show example configuration files
- Include database setup procedures
- Provide troubleshooting guides

## Code Examples

- Include practical, real-world code examples
- Show both simple and complex usage patterns
- Provide examples in multiple programming languages
- Include error handling in examples
- Show common use cases and patterns
- Ensure all examples are tested and functional

## Architecture Documentation

- Document system architecture and design decisions
- Include component diagrams and data flows
- Explain technology choices and trade-offs
- Describe integration points and dependencies
- Document scaling and performance considerations
- Include security architecture details

## Development Workflows

- Document development environment setup
- Explain branching and merging strategies
- Include testing and CI/CD procedures
- Document deployment processes
- Provide debugging and profiling guides
- Include code review guidelines

## Configuration Management

- Document all configurable parameters
- Explain the purpose and valid values for settings
- Show how to customize configurations
- Include production vs development differences
- Document environment-specific configurations
- Provide configuration validation procedures

## Troubleshooting Guides

- Include common error scenarios and solutions
- Document debugging procedures
- Provide performance troubleshooting steps
- Include security-related troubleshooting
- Show log analysis techniques
- Provide escalation procedures

## Migration Guides

- Document upgrade procedures between versions
- Include breaking changes and migration steps
- Provide data migration procedures
- Show how to handle deprecated features
- Include rollback procedures
- Document compatibility matrices

## Best Practices

- Include coding standards and style guides
- Document performance optimization tips
- Provide security best practices
- Include testing strategies and patterns
- Show architectural best practices
- Document deployment best practices

- Provide FAQ sections

- Show configuration reference tables

## Version Management

- Document version-specific features

- Include end-of-life information

## Community Resources

Apply these guidelines whenever creating:

- Code examples and tutorials
- Architecture and system documentation
- Troubleshooting and debugging guides

- Always provide tested and verified examples
